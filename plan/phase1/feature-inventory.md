## Migration checklist notes

1. **Four PDF flows** (D8, D10, I6) plus shared `includes/utils/pdf.php` — highest regression risk; verify Dompdf, local logo path, and output buffering.
2. **GET-based forms** (S6) — all create/edit pages submit via `method='get'`; behavior differs from typical POST/CSRF patterns.
3. **Side effects on read path** — tax receipt generation updates the database during the PDF request (D10).
4. **Bulk lot assignment** (I2) — dynamic `CASE` SQL; `-1` sentinel for "no lot".
5. **Business rules to preserve:** donor delete blocked when items exist (D4); tax receipt eligibility (D9/D10); default bidding-sheet params (I6).
6. **Duplicate / drift:** category accessors in two DB files; `db_lots.php` still has debug `echo` in `add_lot`/`update_lot`; lot details may not show winner name (`get_lot` does not join `bidder`).
7. **Bidders (X1):** not required for parity unless scope expands — lot forms already consume `bidder` table read-only.
